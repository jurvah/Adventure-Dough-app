# Images

Drop your product photos and about-page image into this folder.

Reference them in `index.html` using relative paths like `images/your-photo.jpg`.

Suggested naming:
- `product-1.jpg`, `product-2.jpg`, ... — gallery and shop card images
- `about-photo.jpg` — the photo in the About section
- `logo.png` — if you add a logo to the nav bar

Tip: Resize images to around 800–1200px wide before adding them. Smaller files load faster on mobile.
